# 台灣手語數位詞彙管理系統

> Taiwan Sign Language Vocabulary Admin System
> 與國立中正大學語言學研究所合作開發（2024/09 ~ 2025/08）・已正式上線

語言所的研究團隊需要一套後台，讓多位委員分組輸入手語詞彙、上傳示範影片，並經過多層審查後才正式發布到線上辭典。我負責這套系統的**全端開發**，從需求訪談、資料庫與 API 設計，到部署上線。

## 主要功能

| 功能 | 說明 |
| --- | --- |
| 詞彙管理 | 新增、編輯手語詞彙，管理分類、例句與詞彙間的關聯 |
| 多階段審查 | 詞彙須經組長、總審查逐層確認才會發布，發現錯誤可退回修改 |
| 多角色權限（RBAC） | 管理員、總審查、審查組長、委員各自只能操作對應的資料與功能 |
| 影片串流 | 上傳的手語影片以 FFmpeg 轉成 HLS 分段格式，播放時不必等整個檔案下載 |
| 帳號與分組管理 | 管理員可新增帳號、調整角色與分組、停用帳號 |
| 公告與回報 | 發布系統公告，處理使用者回報的詞彙錯誤 |

## 系統架構

```
┌──────────────┐  HTTPS / REST API   ┌──────────────────┐   JPA / JDBC   ┌─────────┐
│  Vue 3 前端   │ ──────────────────▶ │ Spring Boot 後端 │ ─────────────▶ │  MySQL  │
│ （Nginx 部署）│ ◀────────────────── │  Session + RBAC  │                └─────────┘
└──────────────┘                     └────────┬─────────┘
       ▲                                      │ 上傳影片
       │  HLS 串流（.m3u8 + .ts）              ▼
       └─────────────────────────────  FFmpeg 轉檔 → HLS 片段
```

| 層級 | 技術 |
| --- | --- |
| 前端 | Vue 3、Vue Router、Pinia / Vuex、Bootstrap Vue、Video.js、GoJS、D3 |
| 後端 | Java 17、Spring Boot 3、Spring Security、Spring Session（JDBC）、Spring Data JPA |
| 資料庫 | MySQL |
| 影片處理 | FFmpeg（MP4 → HLS） |
| 部署 | Linux、Nginx |
| 安全性 | BCrypt 密碼雜湊、Cloudflare Turnstile 人機驗證、HttpOnly / Secure Cookie |

## 設計重點

### 1. 詞彙審查狀態機

詞彙不是輸入後就能公開，而是依照語言所的審查流程逐層確認：

```
委員輸入 ──▶ [0] 未審核 / 需修改
                 │ 送出
                 ▼
             [1] 待審查組長檢閱 ──發現錯誤──▶ 退回 [0]
                 │ 確認無誤
                 ▼
             [2] 待總審查檢閱 ────發現錯誤──▶ 退回 [0]
                 │ 確認無誤
                 ▼
             [3] 通過審核 ──▶ 發布到線上辭典
```

後端同時檢查**目前狀態**與**使用者角色**，每個角色只能把詞彙推進到它負責的下一個狀態，避免跳過審查流程。

### 2. 後端權限驗證（RBAC）

登入後，使用者的角色與分組存放在伺服器端的 Session（Spring Session JDBC）。詞彙審查、帳號管理等 API 會在後端檢查角色：即使使用者已登入，角色不符時，後端仍會拒絕該請求，而不是只靠前端隱藏按鈕。

| 角色 | 權限 |
| --- | --- |
| 管理員（`admin`） | 帳號、分組、公告、關聯規則管理 |
| 總審查（`chief_censor`） | 詞彙最終審核 |
| 審查組長（`censor_team_leader`） | 審查所屬分組的詞彙 |
| 委員（`committee`） | 新增與修改所屬分組的詞彙 |

### 3. HLS 影片串流

手語教學影片多為高畫質檔案，整檔下載再播放會等很久。上傳後由後端呼叫 FFmpeg 把影片切成 HLS 片段，前端以 Video.js 播放 `playlist.m3u8`，片段下載到就能開始播放。

## 專案結構

```
sign-language-dictionary/
├── front/                 # Vue 3 前端
│   ├── src/
│   │   ├── views/         # 頁面（詞彙、帳號、公告、回報…）
│   │   ├── components/    # 元件
│   │   └── store/         # 狀態管理
│   └── package.json
└── back/                  # Spring Boot 後端
    ├── src/main/java/com/project/demo/
    │   ├── model/         # 資料模型
    │   ├── dto/           # 資料傳輸物件
    │   └── repository/    # 資料存取介面
    └── pom.xml
```

> **關於未公開的部分**：本系統仍在正式環境運作中，為避免增加線上服務的資安風險，後端 API（Controller）、服務層、安全性設定，以及前端的路由權限與部署設定**未包含在此公開 repo**。此 repo 僅作為作品展示，完整程式碼可於面試時另行展示。

## 我負責的部分

- **需求整理**：與語言所老師訪談，把審查流程整理成四個狀態，逐一確認每一步誰能做什麼後才開始實作
- **後端**：RESTful API、Session + RBAC 權限驗證、資料庫結構設計、統一 API 回傳格式與錯誤處理
- **前端**：Vue 3 後台介面、詞彙與帳號管理頁面、影片播放
- **影音與部署**：FFmpeg 轉 HLS、Linux + Nginx 部署與維護
